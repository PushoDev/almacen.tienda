## 🎯 PROBLEMA IDENTIFICADO

❌ ANTES (Incorrecto):
- El saldo total sumaba directamente todos los saldos sin considerar monedas diferentes
- Ejemplo: $1,000 USD + $24,000 CUP = $25,000 (INCORRECTO - No son comparables)
- No había conversión a moneda principal
- Las tasas de cambio en la tabla de monedas no se utilizaban

❌ IMPACTO:
- Reportes financieros inexactos
- Imposibilidad de comparar saldos en moneda común
- Desconfianza en los números reportados

### 2️⃣ LÓGICA DE CONVERSIÓN DE MONEDAS (Frontend)

📁 resources/js/pages/Cuentas/Index.tsx (Líneas 70-104)

✨ NUEVAS FUNCIONES:

a) Encontrar Moneda Principal:
```typescript
const monedaPrincipal = cuentas.find((c) => c.moneda?.principal)?.moneda;
```

b) Función de Conversión:
```typescript
const convertirAMonedaPrincipal = (saldo: number, moneda: MonedaInfo | null): number => {
    if (!moneda || !monedaPrincipal) return saldo;
    if (moneda.principal) return saldo;
    return saldo / (moneda.tasa_cambio || 1);
};
```

c) Cálculo de Saldo Total (CORREGIDO):
```typescript
const calcularSaldoTotal = () => {
    return cuentas
        .reduce(
            (total, cuenta) =>
                total + convertirAMonedaPrincipal(cuenta.saldo_cuenta || 0, cuenta.moneda),
            0
        )
        .toFixed(2);
};
```

d) Desglose por Moneda (Para Transparencia):
```typescript
const calcularSaldoPorMoneda = () => {
    const saldoPorMoneda: { [key: string]: number } = {};
    cuentas.forEach((cuenta) => {
        const codigoMoneda = cuenta.moneda?.codigo_moneda || 'N/A';
        if (!saldoPorMoneda[codigoMoneda]) {
            saldoPorMoneda[codigoMoneda] = 0;
        }
        saldoPorMoneda[codigoMoneda] += cuenta.saldo_cuenta || 0;
    });
    return saldoPorMoneda;
};
```

## 🔢 EJEMPLO DE FUNCIONAMIENTO

Escenario: Sistema con USD (principal) y CUP

DATOS EN BASE DE DATOS:
┌──────────┬────────────────┬────────┬────────────┐
│ Cuenta   │ Saldo Almacen  │ Moneda │ Tasa Cambio│
├──────────┼────────────────┼────────┼────────────┤
│ Caja 1   │ 1,000.00       │ USD    │ 1.0        │
│ Caja 2   │ 24,000.00      │ CUP    │ 24.0       │
│ Banco    │ 500.00         │ USD    │ 1.0        │
│ Ahorros  │ 12,000.00      │ CUP    │ 24.0       │
└──────────┴────────────────┴────────┴────────────┘

CÁLCULO ANTERIOR (❌ INCORRECTO):
Total = 1,000 + 24,000 + 500 + 12,000 = $37,500 ❌

CÁLCULO NUEVO (✅ CORRECTO):
Total (en USD) =
  + (1,000 / 1.0) = 1,000 USD
  + (24,000 / 24) = 1,000 USD
  + (500 / 1.0) = 500 USD
  + (12,000 / 24) = 500 USD
  ─────────────────────────
  = $3,000.00 USD ✅

TOOLTIP MUESTRA:
USD: $1,500.00
CUP: ₱36,000.00
