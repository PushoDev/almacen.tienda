● Este es el flujo completo, paso a paso, tal cual lo va a vivir el admin (es
  exclusivo para ese rol):

  1. Entra a /disponibles (Precios por Almacén) y ve el botón nuevo "Buscar 
  Producto", junto a "Exportar/Importar Excel" (solo visible para admin).
  2. Click en el botón → se abre un modal.
  3. Busca el producto escribiendo nombre/marca/modelo en un campo con
  autocompletado — la búsqueda es instantánea porque ya tiene todos los
  productos y almacenes cargados en el navegador, no pega contra el servidor.
  4. Selecciona el producto de los resultados.
  5. El modal muestra dos campos: Precio de Venta (obligatorio) y Comisión
  (opcional).
  6. Debajo, el modal lista todos los almacenes donde ese producto está 
  disponible, cada uno mostrando su precio actual ("No definido" si nunca se le
  puso precio).
  7. El admin marca con checkboxes los almacenes donde quiere que se aplique el
  precio que acaba de escribir — puede marcar uno, varios, o todos.
  8. Confirma → se dispara una sola request al endpoint nuevo (PUT 
  /disponibles/bulk-actualizar) con el producto, la lista de almacenes marcados,
  el precio y la comisión.
  9. El backend actualiza todos los almacenes marcados dentro de una sola 
  transacción (todo o nada) — mismo precio y comisión para todos, y deja

  realmente cambió.
  10. El modal se cierra y la tabla/estadísticas de la vista reflejan los nuevos
  precios.

  3 roles. El modal nuevo es un atajo exclusivo de admin para cuando quiere
