🔄 FLUJOS DE OPERACIÓN
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

EXPORTACIÓN:
1. Usuario selecciona almacén en dropdown
2. Usuario hace clic en "Exportar"
3. Sistema valida almacén + tiene productos
4. ProductoExport filtra por almacén_id
5. Excel genera con datos del almacén
6. Usuario descarga archivo automáticamente
7. Notificación de éxito

IMPORTACIÓN:
1. Usuario hace clic en "Importar"
2. Modal abre con selector de almacén
3. Usuario selecciona almacén destino
4. Usuario carga archivo (drag-drop o click)
5. Sistema valida archivo (tipo + tamaño)
6. Usuario hace clic "Importar Productos"
7. Backend procesa fila por fila:
   - Valida datos
   - Busca/crea categoría
   - Busca/crea/actualiza producto
   - Asigna al almacén con cantidad
8. Estadísticas se calculan
9. Notificación con resultados
10. Página se recarga automáticamente
