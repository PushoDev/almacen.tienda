### **Problema 2: Errores de hidratación de React**

**Errores en consola:**
```
In HTML, <tr> cannot be a child of <div>.
In HTML, <div> cannot be a child of <tbody>.
```

**Causa:**
- Los componentes `<Collapsible>` de Radix UI renderizan `<div>` dentro de `<tbody>`
- Esto viola las reglas de HTML para tablas

**No es crítico:** La funcionalidad trabaja correctamente, solo son advertencias.

**Posible solución mañana:**
- Mover el Collapsible fuera del `<tbody>` o usar otra estructura
- O ignorar las advertencias si no afectan la funcionalidad

## 💡 NOTAS IMPORTANTES

### **Fórmula del Saldo Esperado**
```
saldo_esperado = saldo_inicial 
               + ventas_efectivo (a cuentas)
               + ventas_otros (transferencias a cuentas)
               + ingresos_extra
               - gastos
               - transferencias_salientes
               - comisiones_gestor  ← NUEVO
```

**Importante:** Las ventas a clientes (deuda) NO suman al saldo porque ese dinero no entró a las cuentas del vendedor.

### **Comparativa de Cuentas**
- Compara `saldo_cuenta` ACTUAL vs `saldo_cuenta` en cierre anterior
- Si `diferencia > 0` → "subio" 📈 (verde)
- Si `diferencia < 0` → "bajo" 📉 (rojo)
- Si `diferencia = 0` → "igual" - (gris)

### **Comparativa de Clientes**
- Compara `deuda_pago_cliente` ACTUAL vs `deuda_pago_cliente` en cierre anterior
- Si `diferencia < 0` → "mejoro" ✅ (verde) - el cliente pagó deuda
- Si `diferencia > 0` → "empeoro" ⚠️ (rojo) - el cliente debe más
- Si `diferencia = 0` → "igual" - (gris)
