## 7. `config/app.php` — Providers and Aliases sections

**Note:** In Laravel 12, the `config/app.php` file no longer contains a `providers` array or an `aliases` array. Providers are configured in `bootstrap/providers.php` (see below), and class aliases are no longer defined in config (they are autoloaded by Composer).

The full `config/app.php` content (it only has basic application configuration):

```php
<?php

return [

    'name' => env('APP_NAME', 'Laravel'),
    'env' => env('APP_ENV', 'production'),
    'debug' => (bool) env('APP_DEBUG', false),
    'url' => env('APP_URL', 'http://localhost'),
    'timezone' => 'UTC',
    'locale' => env('APP_LOCALE', 'en'),
    'fallback_locale' => env('APP_FALLBACK_LOCALE', 'en'),
    'faker_locale' => env('APP_FAKER_LOCALE', 'en_US'),
    'cipher' => 'AES-256-CBC',
    'key' => env('APP_KEY'),
    'previous_keys' => [
        ...array_filter(
            explode(',', env('APP_PREVIOUS_KEYS', ''))
        ),
    ],
    'maintenance' => [
        'driver' => env('APP_MAINTENANCE_DRIVER', 'file'),
        'store' => env('APP_MAINTENANCE_STORE', 'database'),
    ],
];
```

The registered **service providers** live in `bootstrap/providers.php`:

```php
<?php

return [
    App\Providers\AppServiceProvider::class,
];
```

And the **middleware aliases** are defined in `bootstrap/app.php`:

```php
$middleware->alias([
    'admin' => EnsureUserIsAdmin::class,

    'vendor' => EnsureUserIsVendor::class,
```

```php
namespace App\Http\Middleware;

use App\Models\Moneda;
use Illuminate\Foundation\Inspiring;
use Illuminate\Http\Request;
use Inertia\Middleware;
use Tighten\Ziggy\Ziggy;

class HandleInertiaRequests extends Middleware

    protected $rootView = 'app';

    public function version(Request $request): ?string
    {
        return parent::version($request);
    }

    public function share(Request $request): array

        return [
            ...parent::share($request),
            'name' => config('app.name'),
            'quote' => ['message' => trim($message), 'author' => trim($author)],
            'auth' => [
                'user' => $request->user(),

            'ziggy' => fn(): array => [

                'location' => $request->url(),
            ],
            'sidebarOpen' => ! $request->hasCookie('sidebar_state') || $request->cookie('sidebar_state') === 'true',

                'error' => fn() => $request->session()->get('error'),

                ->orderBy('codigo_moneda')
```

## 10. OBSERVACIONES / POSIBLES MEJORAS

###⚠️ Críticos
1. **`.env` con credenciales reales en el repo** - contiene contraseñas, tokens de Telegram, claves API. Debe estar en `.gitignore` (ya lo está) pero el archivo actual tiene datos sensibles.
2. **Secretos hardcodeados en seeders** - contraseñas de usuarios en DatabaseSeeder.php.
3. **Sin tests de negocio** - 0 tests para ventas, compras, movimientos, reportes, distribuciones.
4. **Spatie Permission instalado pero no usado** - en composer.json pero sin config, se usa RBAC manual.
5. **CheckAlmacenPermission en desuso** - registrado pero comentado en bootstrap/app.php línea 31.

###🔶 Estructurales
6. **Duplicación de páginas** - carpetas `almacenes/Almacenes`, `categorias/Categorias`, `proveedores/Proveedores` (case-sensitive) con contenido duplicado.
7. **Modelos sin type hints en relaciones** - métodos tipo `/** @return void */` en User.php.
8. **Sin Laravel Policies** - la autorización se maneja con middlewares en rutas en lugar de Policies.
9. **Sin Resource/Collection classes** - los controladores devuelven datos crudos en vez de API Resources.
10. **Sin Form Requests en varios controladores** - validación inline en controladores.

###🔷 Arquitectura
11. **Servicios sub-utilizados** - solo 2 services (DashboardStats, Notification). Lógica de negocio en controladores.
12. **Consultas N+1 potenciales** - algunos controladores no especifican `with()` en relaciones.
13. **Queue driver database** - funcional pero menos eficiente que Redis para alto throughput.
14. **Sin caché de consultas pesadas** - reportes que agregan muchos datos sin caching.
15. **Inertia SSR configurado** pero sin build de SSR activo en dev.
